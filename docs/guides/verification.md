# Проверка, журнал, дельта-спеки

Load when: завершаешь задачу, пишешь тесты, правишь `JOURNAL.md` или дельту.

## Перед завершением задачи

Запусти `./scripts/verify.sh` и приложи вывод. Скрипт из корня репозитория выполняет:

1. `npm run typecheck` — `tsc -b --noEmit`.
2. `npm run test:run` — полный прогон Vitest.

Падение любой команды останавливает скрипт.

Точечно, пока идёт серия правок: `npx vitest run <path>` по затронутым тестам. Тест лежит рядом с модулем, отдельная папка `tests/` не заводится.

`npm run dev` поднимает Vite и мок вместе. Прокси `/api` → `http://localhost:3001`.

## Экран

Скрипт браузер не открывает. Если задача меняет UI, маршруты, клиентское состояние или данные на экране, проверь сценарий в браузере: основной путь, пустые и ошибочные состояния, соседние экраны с тем же состоянием.

Маршрут проверь под каждой ролью, которой он доступен, и под ролью, которой он закрыт.

## Журнал

Записи в `JOURNAL.md` вносятся только по команде. Агент сам журнал не пишет.

## Дельта-спеки

Изменения из дельта-спеки, которые затрагивают другие спеки, вносятся в эти спеки только по команде. Пока команды нет, дельта остаётся отдельным файлом, а текст затронутых спек не меняется.
