# Delta Spec: Начальное состояние BuilderDay

## Затронутые спецификации
- `specs/001-save-builder-day.md` (MODIFIED)

## MODIFIED Requirements

### [Spec 001] Как устроен текущий экран
- **Было:** «Черновик даты — локальный `DayDraft`: `workoutName`, `activeKeys`, `texts`. Сохранённый план в него не подгружается».
- **Стало:** «Черновик даты — локальный `DayDraft`: `workoutName`, `activeKeys`, `texts`. Если на `selectCurrentDate` уже есть план, `BuilderDay` один раз заполняет черновик из `GET /api/dayPlan`, чтобы тренер мог его изменить и снова сохранить».

### [Spec 001] Acceptance Criteria
- **Было:** «На дату без локального черновика `BuilderDay` показывает пустой `DayDraft`. Сохранённые `workoutName` и `plan` в конструктор не попадают».
- **Стало:** «На дату без локального черновика `BuilderDay` читает тот же `GET /api/dayPlan?date=`, что и `DayView`. Ответ `{ date, workoutName: "", plan: {} }` оставляет пустой черновик. Иначе `workoutName` черновика равен строке ответа, а в `activeKeys` и `texts` попадают только известные ключи `PlanSectionKey`, которые есть в `plan`. Порядок ключей — `planSectionKeys`. Пустая строка блока остаётся активным блоком. Неизвестный ключ пропускается. Тренер меняет этот черновик и сохраняет его тем же пунктом «Сохранить»».

### [Spec 001] Acceptance Criteria
- **Было:** «Ответ `GET` может заново записать черновик даты, которую тренер уже менял».
- **Стало:** «Черновик даты, который тренер уже менял, ответ `GET` не затирает. Повторный заход на эту дату в той же сессии показывает локальный черновик. Пока запрос даты без черновика не завершился, пустая форма не считается правкой тренера».

### [Spec 001] FSD Placement
- **Было:** «`BuilderDay` план выбранной даты не читает. Подгрузки в черновик нет».
- **Стало:** «`widgets/builder-day/ui/BuilderDay.tsx` вызывает `useDayPlanQuery` из `features/select-day`. Новый эндпоинт, второй `createApi` и отдельный запрос не заводятся. Кэш `DayPlan` общий с `DayView`. Сбор черновика из `DayData` остаётся в виджете».

### [Spec 001] Out of Scope
- **Было:** «Загрузка сохранённого названия обратно в черновик `BuilderDay`» и «Загрузка сохранённого плана обратно в черновик `BuilderDay`».
- **Стало:** «Отдельный эндпоинт изменения (`PUT`/`PATCH`). Повторное «Сохранить» по-прежнему шлёт `POST /api/saveBuilderDay` и заменяет запись даты целиком. Разные планы на одну дату разным спортсменам по-прежнему вне объёма: подгрузка идёт по дате, как `GET`».

### [Spec 003] Out of Scope
- **Было:** «Загрузка плана обратно в конструктор».
- **Стало:** «Подгрузка плана в черновик `BuilderDay`. Это клиент Spec 001. Мок не меняется: `GET` по дате уже отдаёт `{ date, workoutName, plan }`, дата без сохранения — `{ date, workoutName: "", plan: {} }`».
